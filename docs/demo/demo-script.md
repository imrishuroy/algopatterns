# AlgoPatterns Demo Recording Script

## Setup Before Recording

1. Open Chrome/Safari in incognito mode
2. Set browser window to 1280x720 or 1920x1080
3. Hide bookmarks bar (Cmd+Shift+B)
4. Log in with a Pro account
5. Close all other tabs
6. Turn off notifications (Do Not Disturb)

## Recording Flow

### Scene 1: Homepage (0:00 - 0:08)
**URL:** https://algopatterns.in/

**Actions:**
- Show the homepage with all 18 pattern cards
- Slowly scroll down to show patterns
- Hover over "Sliding Window" card (shows hover effect)

**Caption:** "Master Data Structures & Algorithms with AlgoPatterns"
**Caption:** "18 algorithm patterns to ace your coding interviews"

---

### Scene 2: Pattern Tutorial (0:08 - 0:13)

**Caption:** "Each pattern comes with detailed tutorials and explanations"

---

**Caption:** "Interactive visualizers help you understand how algorithms work"

## Post-Recording

1. Trim any dead time at start/end
2. Add captions using the SRT file
3. Export as MP4 (H.264, 1080p)
4. Optional: Add background music (subtle, royalty-free)

## Tools for Adding Captions

- **Kap:** Has basic text overlay
- **iMovie:** Free, built into Mac
- **CapCut:** Free, good for captions
- **DaVinci Resolve:** Free, professional
